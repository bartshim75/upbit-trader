# 포지션 상태 유실 재발 방지

## 개요
업비트 잔고 조회 타임아웃을 실제 잔고 0으로 처리해 정상 포지션을 삭제하던 문제를 수정했다. 잔고 조회 실패와 실제 미보유를 구분하고, 잔고 불일치만으로 포지션 원장을 삭제하지 않도록 변경했다.

## 주요 변경사항
- 잔고 조회를 최대 3회 재시도하고 최종 실패 시 `None` 반환
- 잔고 확인 실패 시 매매·매도 확인·baseline 변경을 상태 보존 상태로 중단
- 포지션 총량이 실제 잔고보다 많아도 자동 삭제하지 않고 매도 안전 캡만 적용
- 대시보드에서 잔고 조회 실패를 실제 0이 아닌 오류로 표시

## 결과
- ✅ 수정된 Python 파일 `py_compile` 통과
- ⏭️ 사용자 요청으로 스모크 테스트 생략
