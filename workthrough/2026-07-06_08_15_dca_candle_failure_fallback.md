# DCA 캔들 조회 실패 fallback 패치

## 개요
정시 DCA 매수 시점에 OHLCV 캔들 조회가 실패하면 전체 매수 사이클이 스킵되던 문제를 수정했습니다. fixed DCA 모드에서는 현재가/잔고/API가 정상이라면 캔들 실패 시 변동성 차단 체크만 생략하고 매수를 계속 진행합니다.

## 주요 변경사항
- 수정한 것: fixed DCA 모드에서 캔들 데이터 없음으로 매수 전체가 스킵되지 않도록 변경
- 개선한 것: 캔들 조회 실패 로그에 티커, 예외 타입, 데이터 row 수 표시
- 개선한 것: requests timeout 값이 None으로 들어와도 기본 API timeout을 강제 적용

## 결과
- ✅ py_compile 통과
- ✅ 스모크 테스트는 사용자 요청 흐름에 따라 생략
